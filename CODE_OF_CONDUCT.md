# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique ideas rather than people, and keep discussions about the work. Harassment of any kind is not tolerated.

Report unacceptable behaviour privately to the maintainer via [GitHub](https://github.com/harshpreet931). Reports are handled confidentially.
